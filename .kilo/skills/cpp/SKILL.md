# C/C++ (AVR/Arduino)

Код проекта — C++ для AVR-микроконтроллера (Arduino Mega 2560, ATmega2560). Ландшафт C++ здесь — консервативный (16 МГц, минимум RAM/Flash).

## Типы данных

- Сырые значения и дельты — `int32_t` (адреса `uint16_t`, `raw_value` из `parameter_update`).
- Значения физических единиц — `float` (только для масштабирования и кэшей настроек).
- Индексы и счётчики — `uint8_t` (до 255).
- Регистровые значения Modbus — `uint16_t`, при приведении к `int16_t` проверяй диапазон (см. `start_move` в `servo_driver.cpp`).
- Адреса VP — `const uint16_t` в `namespace param_addr` (`parameter_addresses.h`).

## Идиомы проекта

- Интерфейсы объявляются в `include/*.h` как классы с `virtual`-методами и `= 0`.
- Конкретные классы наследуют интерфейсы и помечают переопределения `override`.
- Forward declarations для избежания циклических `#include`: `class parameter_storage;` перед использованием в сигнатуре (`axis_motion_translator.h`).
- Приватные поля с префиксом `_`: `_current_raw`, `_translator`, `_busy`.
- Документирующие комментарии в стиле `/// @brief ... @param ... @return ...` перед API; пояснения к членам — `///<` в конце строки.
- `size_t` для длин, `(void)index;` для неиспользуемых параметров в переопределениях.
- Каждый заголовок обёрнут в `#ifndef NAME_H / #define / #endif`.

## Ограничения AVR

- НЕ используй `std::vector`, `std::string`, динамическую аллокацию, рекурсию, большие стеки — проект обходится фиксированными буферами и массивами (например, `_line[]` в `dwin_lcm_simulator.cpp`).
- Избегай `String` (класс Arduino) для накопления; используй `char[]` + `snprintf`/`strtok_r`.
- `Serial.print(F("..."))` — строки во Flash (макрос `F()`), не трать RAM.
- Числа, выходящие за пределы типов, контролируй явно (clamp в `start_move`).
- `delay()` только по необходимости; главный цикл неблокирующий — таймауты через `millis()`.

## Ошибки и диагностика

- Английские идентификаторы, но **строки для человека на русском**.
- Диагностика привязана к подсистемам и имеет префиксы: `[SIM]`, `[DRV]`.
- Неуспех — возврат `false` (а не исключения), состояние ошибки — в поле (`_comm_fault`).
