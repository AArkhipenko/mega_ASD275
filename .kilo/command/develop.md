## В рамках сессии (если передан id сессии)

Если первый аргумент — это id существующей сессии (папка `docs/sessions/<id>`), работай в рамках сессии:
- прочитай `docs/sessions/<id>/session.md`, `docs/sessions/<id>/develop-brief.md` и артефакты из `docs/sessions/<id>/artifacts/`;
- реализуй код по артефактам; проверь сборку `pio run`;
- по завершении обнови статус в `docs/sessions/<id>/session.md`.

## Разово (без сессии)

Если id сессии не передан: реализуй код по артефактам из `docs/artifacts/`, следуя целевой архитектуре из `README.md`, проверь сборку `pio run`.

В обоих случаях: если артефактов для задачи нет — остановись и попроси запустить `/analytics`.
