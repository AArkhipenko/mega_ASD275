Сгенерируй (или перегенерируй) документацию проекта mega_ASD275.

$ARGUMENTS

## Принцип: документация — общее описание проекта

`/docs` генерирует **общее описание проекта** в `docs/generated/` (корень — без подпапок по сессиям). Документация не привязана ни к одной сессии: это единый набор файлов прошивки, который перезаписывается целиком при каждой генерации.

## Источники

1. **Код**: прочитай исходники в `src/`, `include/`, `lib/`, `platformio.ini`. Каждый факт из кода — со ссылкой `файл:строка`.
2. **Артефакты аналитика**: принципы работы, намерения и решения, которых нет в коде.
   - Если аргументом передан id сессии (папка `docs/sessions/<id>` существует) — используй её артефакты `docs/sessions/<id>/artifacts/<id>-*.md` как источник принципов. Это источник, а не привязка: выход всё равно пишется в общий `docs/generated/`.
   - Если аргументов нет — ищи артефакты в `docs/artifacts/<id>-*.md` или `docs/sessions/*/artifacts/` (последние актуальные), чтобы взять принципы работы.

## Набор файлов в docs/generated/

Полностью обнови: `README.md` (индекс + дата + список источников), `overview.md`, `principles.md` (**принципы работы из артефактов аналитика**, которых нет в коде), `modules.md`, `flow.md`, `module-data_source.md`, `module-storage.md`, `module-translator.md`, `module-driver.md`, `module-router-registry.md`, `module-addresses.md`, `main.md`, `features.md`.

- Все факты — на русском, для человека.
- Факт «из кода» — со ссылкой на исходник; факт «из артефактов, не подтверждён кодом» — пометить **(из артефактов аналитика)** и сослаться на артефакт.
- Код не менять.
- В README.md не упоминай конкретные сессии как принадлежность набора: сессии — только перечисление источников, сам набор — общий для проекта.

Если передан список файлов/модулей ($ARGUMENTS, не id сессии) — сначала обнови весь набор целиком, затем особое внимание удели указанным.
