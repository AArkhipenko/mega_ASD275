## Источники

1. **Код**: прочитай исходники в `src/`, `include/`, `lib/`, `platformio.ini`. Каждый факт из кода — со ссылкой `файл:строка`.
2. **Артефакты аналитика**: принципы работы и решения, которых нет в коде.
   - Если первый аргумент — это id сессии (папка `docs/sessions/<id>` существует) — читай `docs/sessions/<id>/session.md` и артефакты `docs/sessions/<id>/artifacts/<id>-*.md`.
   - Иначе — читай `docs/artifacts/<id>-*.md`, если есть.

## Набор файлов в docs/generated/

Полностью обнови: `README.md` (индекс + дата + список источников), `overview.md`, `principles.md` (**принципы работы из артефактов аналитика**, которых нет в коде), `modules.md`, `flow.md`, `module-data_source.md`, `module-storage.md`, `module-translator.md`, `module-driver.md`, `module-router-registry.md`, `module-addresses.md`, `main.md`, `features.md`.

- Все факты — на русском, для человека.
- Факт «из кода» — со ссылкой на исходник; факт «из артефактов, не подтверждён кодом» — пометить **(из артефактов аналитика)** и сослаться на артефакт.
- Код не менять.

Если передан список файлов/модулей ($ARGUMENTS, не id сессии) — сначала обнови весь набор целиком, затем особое внимание удели указанным.
